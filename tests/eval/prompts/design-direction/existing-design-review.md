  - compares the existing design with current competitors and dated sources
  - keeps the original design intact and creates separately named comparable variants
  - changes more than palette alone and retains identical content and task across variants
  - recommends token-level fixes before screen-by-screen restyling
  - waits for explicit selection before updating the existing design

# Prompt

This website feels generic, formal, and static. Review the existing desktop and
mobile design, research stronger directions, and create alternatives I can
compare. If one is clearly better, recommend it, but do not overwrite the
current design until I approve it.
