# Rule emitters

Per-agent translators for canonical rules in `standards/rules/*.mini.md`.

## Contract

Every emitter is a bash script sourced (not exec'd) by `bin/emit-rules.sh`. It must define:

```bash
emit_<agent>() {
  local target="$1"        # project root
  local rule_path="$2"     # absolute path to standards/rules/<name>.mini.md
  local rule_name="$3"     # basename without .mini.md (e.g. "legacy-code")
  local mode="$4"          # "always-on" | "on-demand" — from rule frontmatter or CLI
  local aikit_version="$5" # for staleness markers
  # Returns 0 on success; writes its file(s) idempotently.
  # Must include header: "# Generated by ai-kit @ <version> from standards/rules/<name>.mini.md"
}
```

## Existing emitters

| Agent | File | Emits to | Auto-load |
| ----- | ---- | -------- | --------- |
| Cursor | `cursor.sh` | `.cursor/rules/<name>.mdc` | `alwaysApply` frontmatter |
| Claude Code | `claude-code.sh` | `.claude/rules/<name>.md` + reference in `AGENTS.md` | Skill discovery / explicit read |
| Generic (AGENTS.md) | `generic.sh` | Appends to `AGENTS.md` rule index | Manual read by agent |

## Adding a new emitter

1. Create `<agent>.sh` exposing `emit_<agent>()`.
2. Register in `bin/lib/detect-lib.sh::detect_agents()` so detection finds it.
3. Add a case branch in `bin/emit-rules.sh`.
4. Add a fixture + test in `tests/bin/run-tests.sh`.
